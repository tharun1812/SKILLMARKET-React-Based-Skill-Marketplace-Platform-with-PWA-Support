# SkillMarket — Skill Marketplace Platform

A React-based skill marketplace platform with Progressive Web App (PWA) support, designed to help users discover skills, connect with others, and manage skill-related requests.

## Features

- Browse and discover skills in the marketplace
- User registration, login, and profiles
- Create and manage skill listings
- Submit and manage skill requests
- Reviews and ratings
- Responsive user interface
- Progressive Web App (PWA) support
- Offline support

## Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Backend / Database:** Supabase
- **Testing:** Automated tests for application functionality

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/tharun1812/SkillMarket-React-Based-Skill-Marketplace-Platform-with-PWA-Support.git
```

Enter the project directory:

```bash
cd SkillMarket-React-Based-Skill-Marketplace-Platform-with-PWA-Support/skillmarket
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Environment Configuration

If the application requires Supabase credentials, configure the environment variables using the names provided in `.env.example`. Never commit actual credentials, API secrets, or passwords.

## Project Structure

- `src/components/` — Reusable UI components
- `src/pages/` — Application pages
- `src/context/` — Application state and context
- `src/lib/` — Utilities, services, and application logic
- `public/` — Static assets and PWA files
- `supabase/` — Database migrations and tests
